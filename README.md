# lirix-legal

Pages légales publiques pour Lirix (politique de confidentialité, suppression de compte, CGU, mentions légales).

Hébergé sur GitHub Pages — nécessaire car ces URLs doivent être publiquement accessibles pour la review App Store / Play Store, indépendamment de l'app installée.

Contenu généré depuis `packages/i18n/src/locales/{fr-FR,en-US}/legal.json` du repo privé `lirix` — ne pas éditer ces fichiers HTML à la main, régénérer depuis la source.
